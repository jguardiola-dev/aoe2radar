Spoiler-free by design

Knowing the result ruins the game. aoe2radar is built so you only find out when you decide to.

  • No winner in the list. The match list never shows who won, the ELO change or the game length.
  • ELO that doesn't tell. Watchlist ELO only refreshes when you open the app, never when you search.
  • A timeline with no end. In the viewer, everything on screen comes only from what has happened so far, and the timeline doesn't reveal how long the game lasts. Coming soon
  • You decide. Reveal result is always one deliberate click away.

Always up to date

Install it once. From then on, the app and its data keep themselves current.

  • It updates itself. The installed app downloads new versions in the background and applies them when you close it. If a start ever fails, it goes back to the previous version on its own.
  • Nightly data. Player profiles, ladders and civ stats are prepared every night, so the app asks the live services for as little as possible.
  • Current patch. The tech tree comes from aoe2techtree and follows every new patch.
  • Live when it matters. Live now and game alerts update in real time through aoe2companion.

Install it in three steps

  1. Download aoe2radar-X.Y-setup.exe from the latest release.
  2. Run it. It installs for your Windows user only, without administrator rights, and adds a Start menu entry.
  3. If SmartScreen warns with Windows protected your PC, click More info → Run anyway. The installer isn't code-signed yet, which is why Windows warns.

Rather not install anything? Every release also has a zip: unzip it into its own folder and open aoe2radar.exe.

Frequently asked questions

Is it really free?

Yes. No ads, no account and no paid version.

Does it touch the game or my account?

No. It doesn't modify Age of Empires II and never asks for your login. It reads public match data, downloads recs and, only if you ask, opens a game in AoE2 so you can spectate it.

What does it send about me?

Nothing. No analytics, no telemetry. Your settings and lists stay on your PC.

Is there a Mac or Linux version?

Not for now: aoe2radar is a Windows app, like the game and its recs.

And if I do want to know who won?

Right-click a game → Reveal result…, or turn on Show results to see them all.

Can I change the language or the theme?

Yes. It speaks English and Spanish, has light and dark themes and three font sizes. The first time you open it, a short guide lets you choose, and you can bring it back from Settings.
